# 🌐 Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript**.  
The website showcases my profile, skills, achievements, projects, and provides a way to connect with me through my social profiles and contact section.

## 🚀 Live Preview

[View Portfolio](#)

---

## 📌 About The Project

This project is a personal portfolio website created to present my academic background, technical skills, achievements, projects, and other professional information in a clean and responsive design.

The website is designed to work across desktop and mobile screen sizes.

---

## ✨ Features

- Responsive portfolio design
- Fixed navigation bar
- Smooth scrolling between sections
- Home/About section with profile information
- Skills section
- Achievements section
- Achievement image with hover effect
- Contact section
- Download CV functionality
- GitHub profile link
- LinkedIn profile link
- Mobile responsive navigation menu
- Interactive hover effects
- Gradient text and buttons
- Custom scrollbar
- Footer section

---

## 🛠️ Technologies Used

### HTML5
Used to create the structure and content of the website.

### CSS3
Used for:
- Layout and positioning
- Responsive design
- Colors and typography
- Hover effects
- Animations and transitions
- Grid and Flexbox
- Mobile view styling

### JavaScript
Used for:
- Mobile navigation menu
- Button click events
- CV download functionality
- GitHub and LinkedIn navigation
- DOM manipulation and user interactions

### Font Awesome
Used for icons throughout the website.

### Google Fonts
Used for custom typography, including the Poppins font.
